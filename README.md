# Shift — Modern Sliding Puzzle

Shift is a responsive, dependency-free sliding puzzle rebuilt for mouse, touch, and keyboard play.

## Highlights

- Animated 3×3, 4×4, and 5×5 boards
- Every shuffle is solvable because it is produced through legal moves
- Tap, multi-tile row/column slide, swipe, drag, and arrow-key controls
- Move counter, timer, undo, hints, win celebration, and persistent best times
- Dark and light themes with reduced-motion support
- Optional lightweight sound feedback

Open `index.html` directly in a modern browser. Run `node tests.js` for the small engine test suite.
